# Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173. Requires Node 20.19 or later.

## Facilitated workshop

1. Before the day: send participants Workshop → module 0. If the workshop ends with a real AI-DLC run, collect readiness checks 1, 2 and 4 from each team a week ahead (AI-DLC facilitator guide).
2. Open Workshop, keep **Facilitated** selected, and run modules 1–8 in order. Each timed module is 90 min session + 45 min Q&A + 45 min capstone.
3. Use **Show answer** on each checkpoint question during Q&A.
4. In module 8, each team downloads `vision.md` and `technical-environment.md` from Reports and can start a real run with the command shown there.

## Self-paced

1. Open Workshop and select **Self-paced**.
2. Work through each module's steps, ticking them off, and answer the checkpoint questions. Answers are checked immediately; progress stays in this browser.

## Trying it out

Pick **Load sample…** in the top bar to fill every page with a fictional case. Follow the **Next** chip in the bottom-right corner.

## Saving work

Select **Save** to keep the use case in this browser, or download the case JSON from Reports to move it elsewhere. **Open saved** and **Import JSON** bring it back.
